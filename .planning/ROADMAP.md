# Roadmap: Quiz for Client — Рекрутинговый лендинг + квиз

## Overview

Путь от пустого репозитория до полностью рабочей воронки рекрутинга: сначала появляется живой лендинг с вакансией на GitHub Pages, затем на него добавляется пошаговый квиз-анкета с разными типами вопросов, и в конце вся воронка замыкается интеграциями — ответы кандидата мгновенно улетают в Telegram клиенту, а конверсия фиксируется через Facebook Pixel на странице "Спасибо".

## Phases

**Phase Numbering:**
- Integer phases (1, 2, 3): Planned milestone work
- Decimal phases (2.1, 2.2): Urgent insertions (marked with INSERTED)

- [ ] **Phase 1: Лендинг и деплой** - Живой лендинг с вакансией на GitHub Pages с CTA-кнопкой на квиз
- [ ] **Phase 2: Квиз-анкета** - Пошаговый квиз с разными типами вопросов, прогрессом и навигацией
- [ ] **Phase 3: Отправка заявки и трекинг** - Ответы уходят в Telegram, кандидат видит "Спасибо", событие Lead в FB Pixel

## Phase Details

### Phase 1: Лендинг и деплой
**Goal**: Кандидат видит лендинг с вакансией на живом публичном URL и может перейти к квизу
**Mode:** mvp
**Depends on**: Nothing (first phase)
**Requirements**: LAND-01, LAND-02, LAND-03, DEPL-01, DEPL-02
**Success Criteria** (what must be TRUE):
  1. Сайт доступен по публичному URL на GitHub Pages
  2. Пользователь видит лендинг с фоновым изображением/цветом и коротким текстом о вакансии
  3. Пользователь видит CTA-кнопку, ведущую к квиз-анкете
  4. Лендинг корректно и адаптивно отображается на экране телефона (mobile-first)

### Phase 2: Квиз-анкета
**Goal**: Кандидат проходит пошаговый квиз с разными типами вопросов и понятной навигацией
**Mode:** mvp
**Depends on**: Phase 1
**Requirements**: QUIZ-01, QUIZ-02, QUIZ-03, QUIZ-04, QUIZ-05, QUIZ-06
**Success Criteria** (what must be TRUE):
  1. Пользователь видит один вопрос на экране за раз
  2. Пользователь может отвечать на вопросы типа "один вариант" (radio), "несколько вариантов" (checkbox) и "открытый текст" (textarea)
  3. Пользователь видит индикатор прогресса (шаг N из M)
  4. Пользователь может перемещаться вперёд и назад между вопросами кнопками "Далее"/"Назад"

### Phase 3: Отправка заявки и трекинг
**Goal**: Клиент мгновенно получает заявку в Telegram с полными ответами, кандидат видит страницу благодарности, а конверсии фиксируются в Facebook Pixel
**Mode:** mvp
**Depends on**: Phase 2
**Requirements**: INTG-01, INTG-02, INTG-03, FINL-01
**Success Criteria** (what must be TRUE):
  1. После завершения квиза ответы автоматически отправляются в Telegram-бот клиента
  2. Пользователь перенаправляется на страницу "Спасибо" с уникальным URL и текстом благодарности после отправки
  3. Facebook Pixel PageView срабатывает на всех страницах сайта
  4. Facebook Pixel Lead срабатывает при загрузке страницы "Спасибо"
