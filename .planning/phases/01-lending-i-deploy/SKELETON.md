# SKELETON: Лендинг и деплой (Walking Skeleton)

**Дата:** 2026-09-04
**Фаза:** 01-lending-i-deploy

## Назначение

Этот документ фиксирует архитектурные решения первого (walking skeleton) деплоя проекта — тонкого сквозного стека "браузер → статический HTML на GitHub Pages". Последующие фазы (2 — квиз, 3 — интеграции) достраивают функциональность поверх этой основы, не пересматривая базовые решения ниже.

## Технологический стек

- **Frontend:** чистый HTML5 + CSS3 + vanilla JS. Без фреймворков, без бандлеров, без npm-зависимостей.
- **Хостинг:** GitHub Pages, источник — ветка `main`, корень репозитория (`/`).
- **Тестирование:** встроенный `node --test` (Node.js ≥ 18) для лёгких E2E smoke-тестов на основе чтения HTML-файлов через `fs`. Никаких внешних test-раннеров (Jest/Playwright) — не нужны для статического сайта такого масштаба.
- **CI/деплой:** ручной/CLI-деплой через `git push` + `gh api` для включения Pages. Отдельный workflow не создаётся, т.к. GitHub Pages сам билдит статику из ветки при пуше.

## Структура директорий

```
/
├── index.html          # Лендинг (Фаза 1)
├── quiz.html            # Квиз — в Фазе 1 это заглушка, в Фазе 2 станет полноценной анкетой
├── thank-you.html       # Появится в Фазе 3 (страница "Спасибо" + FB Pixel Lead)
├── css/
│   └── style.css         # Общие стили, mobile-first
├── js/
│   └── (появится в Фазе 2 для логики квиза)
├── assets/
│   └── (изображения/фоны — добавляются по мере поступления от клиента)
└── tests/
    └── landing.test.mjs  # E2E smoke-тест лендинга (node --test)
```

## Ключевые решения

| Решение | Обоснование |
|---------|-------------|
| Без фреймворка/бандлера | GitHub Pages отдаёт статику как есть; сайт маленький, сложность не нужна |
| Фон через CSS custom property `--hero-bg` | Реальное фоновое изображение клиент предоставит позже; переменная позволяет заменить фон одной строкой CSS без переписывания разметки |
| `quiz.html` как заглушка в Фазе 1 | CTA-кнопка лендинга должна вести на реальный (не "#") URL уже в Walking Skeleton; Фаза 2 заменит содержимое файла на полноценный квиз, путь/имя файла не меняется |
| `node --test` вместо npm-фреймворка | Ноль зависимостей, ноль `package.json`, соответствует ограничению "только статика на GitHub Pages" |
| Деплой через `gh api repos/.../pages` | Автоматизация вместо ручных кликов в UI, повторяемо и проверяемо |

## Не входит в эту фазу

- Логика квиза (типы вопросов, прогресс, навигация) — Фаза 2
- Отправка в Telegram, Facebook Pixel, страница "Спасибо" — Фаза 3
- Реальное фоновое изображение/брендинг клиента — подставляется когда клиент предоставит ассеты (переменная `--hero-bg` уже готова к замене)
