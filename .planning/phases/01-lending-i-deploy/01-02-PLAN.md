<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| GitHub API (`gh api`) → настройки репозитория | Аутентифицированный CLI-доступ разработчика, изменяет публичные настройки Pages конкретного репозитория |
| GitHub Pages CDN → браузер пользователя | Публичный HTTPS-эндпоинт без аутентификации |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|------------------|
| T-01-05 | Tampering | Источник сборки GitHub Pages | mitigate | Источник Pages явно зафиксирован как ветка `main`, путь `/` — сборки из форков/PR не включены |
| T-01-06 | Elevation of Privilege | `gh api` вызов включения Pages | accept | Используется собственная аутентифицированная сессия разработчика (`gh auth`), действие ограничено одним репозиторием и обратимо через тот же API |
| T-01-07 | Information Disclosure | Публичный контент на живом URL | accept | Контент этой фазы — только публичный маркетинговый текст о вакансии, PII или секретов (токены Telegram/FB Pixel появятся не раньше Фазы 3) не содержит |
</threat_model>
